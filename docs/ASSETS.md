# Art sources

- `public/assets/grass-tile.png` is tile 024 from **Tower Defense (Top-Down)** by Kenney Vleugels, downloaded from [OpenGameArt](https://opengameart.org/content/tower-defense-300-tilessprites). Licensed **CC0 1.0**.
- `public/assets/farm-hay.png`, `farm-crates.png`, and `farm-cereals.png` are from the **Farming Set Pixel Art** by ScratchIO, downloaded from [OpenGameArt](https://opengameart.org/content/farming-set-pixel-art). Licensed **CC0 1.0**.
- Defense, predator, armor, robot, ostrich, and projectile shapes in `src/Sprites.tsx` are original SVG drawn for this project. No Bloons game art or proprietary sprites are included.

- `public/assets/coop-defense-thumbnail.jpg` is an original generated game thumbnail with centered title, used for link previews.
- Farm carts, hay bales, and crops drawn in `src/main.tsx` are original SVG decorations placed away from tower pads.
